# 국내 여행지 지출액 & 관광객 만족도 분석 시스템

국가통계포털(KOSIS) 및 한국문화관광연구원의 국민여행조사 실측 CSV 데이터를 기반으로 **17개 광역시도별 비용·만족도 비교, 상관분석, OLS 단순회귀분석, 4분면 예산별 가성비 매트릭스, AI 후속질문 질의응답**을 수행하는 웹 분석 플랫폼입니다.

---

## 📌 핵심 통계 원칙 준수

1. **소비자물가지수(CPI) 지역 간 절대 비교 배제**:
   - 통계청 지침에 따라 기준시점 대비 변동률 지표인 CPI를 지역 간 생활물가 비교에 쓰지 않고, 국민여행조사의 **실제 여행 지출액 및 체감 물가 만족도 설문 실측치**만을 비교합니다.
2. **실측 데이터 100% 사용**:
   - 가짜 수치나 임의 가중치를 생성하지 않으며, CSV에 존재하는 실제 행/열만 결합합니다.
3. **표본수(N) 및 통계적 유의성(p-value) 명시**:
   - 17개 시도 유효 관측치 $N$과 자유도 $df = N-2$를 명시하고, $p < 0.05$ 기준 통계적 유의성 여부를 명확히 표시합니다.
4. **서로 비교 불가능한 통계의 결합 금지**:
   - 서로 다른 조사 단위(원, %, 점수)를 임의로 단순 합산하지 않고, 축을 분리하거나 정규화하여 표시합니다.

---

## 🛠️ 주요 기능

- **1. 지역별 평균 비교**: 17개 시도별 실측 수치 막대 차트, 전국 평균선 및 순위 테이블
- **2. 상관관계 & 회귀분석**: 
  - 피어슨($r$), 스피어만($\rho$) 상관계수
  - OLS 선형회귀방정식 ($Y = \beta_0 + \beta_1 X$), 결정계수($R^2$), $t$-통계량, $p$-value
  - 산점도 및 추세선 인터랙티브 시각화 (Chart.js)
  - 자동 학술 통계 검정 보고서 출력
- **3. 예산별 합리적 여행지 (4분면 매트릭스)**:
  - 제2사분면: **저비용·고만족 (최고 가성비 추천 여행지)**
  - 제1사분면: **고비용·고만족 (프리미엄 여행지)**
  - 제3사분면: 알뜰 실속형 / 제4사분면: 비효율 주의 지역
- **4. KOSIS CSV 업로드 & 카탈로그 관리**:
  - 드래그 앤 드롭 지원
  - CP949 / EUC-KR / UTF-8 인코딩 및 KOSIS 2단 헤더 자동 인식
- **5. AI 후속질문 분석가**:
  - 실측 데이터와 회귀분석 결과를 바탕으로 가성비 여행지, 상관관계 해석 등의 질문에 데이터 근거를 들어 답변

## 🌐 무료 웹 배포 안내 (Render / PythonAnywhere)

### 옵션 1. Render (추천, 무료 호스팅)
1. GitHub 저장소에 이 폴더(`korea-travel-insight`)를 푸시합니다.
2. [Render](https://render.com/) 접속 후 **New > Web Service** 선택.
3. 리포지토리 연결 후 설정:
   - **Environment**: Python
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app` (또는 `python app.py`)
4. 배포 완료 시 무료 `https://...onrender.com` 도메인과 HTTPS가 자동 제공됩니다.

### 옵션 2. PythonAnywhere
1. [PythonAnywhere](https://www.pythonanywhere.com/) 무료 계정 생성
2. 코드 업로드 후 Web 탭에서 Flask 앱으로 `app.py` 지정
